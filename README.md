\# 🎓 StudyFlow – Student Hub



A Java Swing desktop application for student productivity and technical learning.



\## ✨ Features



\- 📊 \*\*Dashboard:\*\* Task totals, completed tasks and study progress.

\- 📚 \*\*Study Planner:\*\* Add, edit, delete, search, filter and complete tasks.

\- 🎮 \*\*TechQuest:\*\* Code Arena, ML Lab and Debug Rush.

\- ⏱️ \*\*Game System:\*\* Timer, scores, XP and answer explanations.

\- 🤖 \*\*Study Buddy:\*\* Offline explanations for Java, Python and Machine Learning.



\## 🛠️ Technologies



\- Java 21

\- Java Swing

\- AWT

\- Object-Oriented Programming

\- File Handling



\## 🚀 How to Run



1\. Install JDK 17 or newer.

2\. Download this repository.

3\. Extract the project.

4\. Run `run.bat`.



Or use:



```bash

javac -encoding UTF-8 -d out src/StudyFlow.java

java -cp out StudyFlow

```
