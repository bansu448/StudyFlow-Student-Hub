STUDYFLOW — FIXED STUDENT HUB
=============================
Includes:
- Study dashboard with live task totals, completed count and progress
- Planner: add, edit, delete, mark complete, search and filters
- Local task persistence
- TechQuest: Code Arena, ML Lab and Debug Rush
- Timer, score, XP and answer explanations
- Study Buddy offline helper

The button rendering uses a basic Swing button UI to avoid Windows Look-and-Feel white buttons with invisible white text.
Use JDK 17+ (JDK 21 recommended).
Chatbot note: Study Buddy uses local prepared explanations. It is not a live AI model.
